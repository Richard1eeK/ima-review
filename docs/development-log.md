# 开发记录

## 2026-10-02：确定范围与部署方式

已确认的决策：

- 建立独立的 `ima-review` 应用，不改动现有 IELTS 主应用。
- 资料来源为 ima 英语笔记；保留笔记本、笔记、内容块和内容版本，解析真实内容后再出题。
- 每日新学、到期复习和开放应用题形成统一任务。先独立作答，提交后看参考，使用四档自评；开放答案不自动判错。
- 使用 `ts-fsrs` 调度学习与复习。原答、修订、外部反馈及历史记录分开保存；归档保留历史。
- 运行时不调用 AI。外部评阅由用户主动复制后自行完成；Kimi 仅由用户自行用于界面设计。
- 目标为常开的 Mac mini，Tailscale Serve 私有 HTTPS，只允许自己的 Tailscale 身份访问。
- 后台采用用户级 LaunchAgent：登录后运行，启动/每日/手动同步。每日同步由服务器内部调度，不另装 cron。
- `20:30` 是网页内学习待办；此次没有授权安装系统通知或发送消息。
- SQLite 与备份放在静态目录之外。后台凭证从 `~/.config/ima` 或指定凭证目录读取，浏览器不持有凭证。
